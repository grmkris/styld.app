# v1 production usage, 2026-10-29

These are aggregate counts from v1's production Postgres, used to decide what v2 ports (`docs/ROADMAP.md`). Each
query ran in a forced read-only session; nothing was written and no personal data was taken. PostHog was not read:
the environment holds only ingest keys, no personal API key.

**Range:**

- All time: 2026-02-24 (first sign-up) to 2026-10-29 11:32 UTC.
- 90 days: from 2026-07-31.
- 30 days: from 2026-09-29.

Production ran the pre-launch build, because the dev → main PR #93 was unmerged.

## Caveats

- **Small numbers.** Most rows come from one to four accounts, mostly admins.
- **History is incomplete:**
  - 29 `ai_token_usage` rows have no cost;
  - the credit ledger starts on 2026-06-13;
  - `session` keeps only 83 rows, so older activity is undercounted.
- **Anonymous click-outs** all fall between 2026-10-18 and 2026-10-29, peaking at 422 a minute.
